## Os 5 Ângulos Psicológicos

### 1. DOR
```
Hook: "Fornecedor quer à vista e você não tem?"
→ Identifica o problema no momento presente. Sem solução ainda.
→ Funciona quando o comerciante está no aperto agora.
```

### 2. ASPIRAÇÃO
```
Hook: "Seu negócio merece continuar crescendo"
→ Aponta para o futuro desejado, não o problema presente.
→ Funciona com comerciantes em modo crescimento.
```

### 3. EMPATIA
```
Hook: "Quem tem comércio sabe: às vezes aperta"
→ Você entende, não julga. Está do lado do comerciante.
→ Funciona com públicos que se sentem culpados por precisar de crédito.
```

### 4. URGÊNCIA
```
Hook: "A virada do mês tá pesada pro seu caixa?"
→ Timing específico. Momento de crise iminente.
→ Funciona no final do mês, datas de pagamento.
```

### 5. PROVA SOCIAL
```
Hook: "Comerciante que é comerciante sabe o que é aperto"
→ Outros passaram por isso. Você não é o único.
→ Funciona com públicos que têm vergonha de buscar crédito.
```

## Regras Absolutas

**NUNCA:**
- Valores em reais (R$ X)
- "Aprovação garantida" ou variações
- "Sem consulta SPC/Serasa"
- "Liberação imediata" ou "na hora"
- Taxas de juros (%a.m., %a.a.)
- Nome da empresa, marca ou razão social

**SEMPRE:**
- Ao menos 1 termo seguro por copy
- CTA exatamente como aprovado
- Hook em até 80 caracteres
- Tom de conversa entre conhecidos
